## 🚀 Featured Project

### [emotion-chat-bot](https://github.com/hermeschen1116/emotion-chat-bot)

An academic team project exploring **simulated internal emotional states and goal-directed response selection in conversational AI**.

The project grew from my broader interest in autonomous and adaptive models. It explores how a conversational system might represent a simulated, self-like emotional state and guide response selection toward configurable target states.

My main contributions included:

- Designing the overall system architecture and integration approach.
- Preparing datasets and training or fine-tuning model components.
- Integrating the components into an interactive conversational prototype.

Individual model components were evaluated, and the prototype was tested through preliminary conversations. However, the broader research goals were not systematically validated, and the project did not establish continual learning or autonomous network growth.
