## 🚀 Featured Project

### [emotion-chat-bot](https://github.com/hermeschen1116/emotion-chat-bot)

An academic team project exploring **model autonomy through simulated internal emotional states and goal-directed response selection**.

Motivated by my interest in model autonomy, this project investigates how a conversational system might represent an internal emotional state of its own and use configurable target states to guide its response selection.

Rather than relying solely on the user's emotional input, the proposed architecture considers the system's simulated internal state and predicted future states when evaluating candidate responses.

My main contributions included:

- Designing the overall system architecture and integration approach.
- Preparing datasets and training or fine-tuning model components.
- Integrating the components into an interactive conversational prototype.

Individual model components were evaluated, and the prototype was tested through preliminary conversations. However, the broader goals of simulated internal emotional states and autonomous response selection were not systematically validated at the full-system level.
